How the NHY app handles the menu, the waiting table and the empty shelf

Tap Tap Go. ⚓ Order in 3 Seconds. One operating system for the floor, the counter and the shop.

The printed menu is still on the counter. Someone has to type every category, every price and every “ask the kitchen” note into the system before a guest can order it. At the same time a table is trying to catch a server’s eye, the bar is out of the garnish nobody logged, and the shop’s best-seller has no photo because the shoot never happened.

That is the day NHY is built for. It is the React Native app inside Nautical POS — the owner console at app.nautical.co.in — and it is meant for restaurant owners, café owners, bar managers and retail shop owners. Same deck. Different catalogue. The point is not another login. The point is that the menu, the order and the stock finally share a screen.

Stop retyping the card

An AI menu builder is only useful if it looks like the card your floor already uses. In NHY you set categories with colour and imagery, then items with a price, calories, and flags for veg, spicy and featured. Availability can follow the service: Breakfast, Lunch or Dinner. A café can hide the breakfast bun after eleven. A bar can keep the lunch plates off the evening card. A shop does not need dayparts — it needs a catalogue.

If the card already exists on paper, Import from photo reads a printed menu photo and builds the categories and items for you. You still check the names and prices. You do not start from a blank list. Retail catalogues can come in from a Shopify CSV, so a boutique or a grocery aisle does not have to be typed by hand either. This is restaurant POS software that also behaves as a retail inventory management app, because the catalogue is the same job in both rooms: what you sell, what it costs, and whether it is on today.

The table that should not have to wave

Contactless ordering fails when it asks the guest to install an app. NHY’s QR code ordering system is a code per table. The guest opens the phone camera, scans, and lands on a web menu. No download. They pick a portion — Quarter, Half or Full — apply a coupon if they have one, and see a live summary: subtotal, service charge, tax and discount, before they submit.

That is the same motion in four rooms. A restaurant table orders the thali without waiting for a pen. A café counter lets the queue build its own cup. A bar table sends the round while the bartender is on another well. A retail shop can put the same QR on a shelf talker so a guest checks size, price and availability without blocking the till. The brand line is literal here: Tap Tap Go. The order should take about as long as reading the card, not as long as finding a server.

The guest should not need an app, a wave, or a second copy of the menu. The phone camera is enough.

One pipeline, four kinds of floor

Once the order exists it should not live in a chat thread. NHY moves it Pending, then Preparing, then Ready, then Completed. You can send the receipt and filter by date, table, payment method and status. A kitchen reads Preparing. A pass reads Ready. A café barista and a bar well use the same words. A shop uses the same board for picked and handed over, so the counter is not guessing which bag is whose.

Find the empty shelf before the guest does

The painful version of inventory is discovering the stock ran out mid-shift, after the order is already in. NHY keeps Food stock and Retail stock, raises low-stock alerts, and supports purchase orders and transfers between locations. A restaurant moves prep from the central kitchen to the outlet. A bar transfers a spirit case. A shop moves a size run from the warehouse to the floor. The alert is the point: you see the short item on the dashboard before the line does.

Run the business sits beside that. The dashboard shows today’s revenue, orders and average order value. Billing, team accounts and store settings live on the same deck, so a manager is not hopping between a till app and a spreadsheet to see who is on shift.

The photo that never got taken

Marketing usually waits on a camera, a model and a free afternoon. AI Marketing Studio is the shortcut that ships in the app: AI Trial Lab for product mockups, AI-generated video ads for any item, and AI try-on for products. A café can mock up the seasonal bun. A bar can cut a short clip of the signature serve. A boutique can try a garment on a figure without booking a studio. It does not replace a good product. It removes the week where the item is live and still has no picture.
